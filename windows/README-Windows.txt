КОНВЕРТЕР ДЛЯ WINDOWS — ПОЛНЫЙ КОМПЛЕКТ
=======================================

Внутри уже всё, что нужно для работы без интернета:
  • само приложение Konverter;
  • LibreOffice (документы DOC, ODT, RTF, таблицы, презентации, EPUB);
  • Ghostscript (PDF в картинку, сжатие PDF);
  • qpdf (пароль на PDF);
  • среда Microsoft Visual C++ для внутренних модулей;
  • модель распознавания речи (150 МБ) — интернет для субтитров не нужен.

ТРЕБОВАНИЯ
Windows 10 или 11, 64-битная. Интернет нужен только для скачивания архива.

УСТАНОВКА (один раз)
1. Распакуй архив в постоянную папку, например C:\Konverter
   (не запускай прямо из архива — программа не сможет сохранить настройки).
2. Запусти INSTALL.bat (двойной клик, затем согласись с запросом администратора).
   Скрипт поставит LibreOffice, Ghostscript, среду C++, создаст ярлыки
   «Konverter» на рабочем столе и в меню «Пуск» и запустит приложение.
3. Если Windows покажет «Система защитила ваш компьютер» — «Подробнее» →
   «Выполнить в любом случае» (программа без подписи).

Если INSTALL.bat не запускали, приложение при первом запуске само предложит
доустановить LibreOffice и Ghostscript из папки setup — согласись, это 1–2 минуты.

КАК ПОЛЬЗОВАТЬСЯ
Начни тащить файл из Проводника (или с рабочего стола) и нажми кнопку:
  Shift  колесо смены формата
  Alt    колесо инструментов
  Ctrl   колесо действий (копия, путь, ZIP, дубль, переименовать, в папку, на стол)
Брось файл на нужный сегмент. Результат появится рядом с оригиналом.
Можно тащить сразу несколько файлов и папки. Окно программы тоже принимает файлы.
Иконка в трее (рядом с часами): открыть окно, настройки, выйти.

ИНСТРУМЕНТЫ (Alt)
  Видео: без звука, обрезать, сжать, склеить, кадры, размер, ИИ-увеличение, звук, субтитры
  Звук: обрезать, сжать, звук (громкость, шум, тишина, скорость), склеить, текст речи
  Фото: сжать, размер, повернуть, без метаданных, в один PDF, текст с фото, водяной знак,
        ИИ-увеличение, убрать фон
  PDF: объединить, по страницам, повернуть, сжать, пароль

О КАЧЕСТВЕ PDF
Документы (DOC, DOCX, ODT, RTF, XLS, PPT, EPUB) превращаются в PDF через
LibreOffice — вёрстка, шрифты, таблицы и картинки сохраняются как в оригинале.
Если LibreOffice не установлен, приложение предупредит, что PDF будет
упрощённым (без точной вёрстки), и предложит установить его.

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
1. Запусти DIAGNOSTIKA.bat — он покажет, что установлено, и откроет журнал.
2. Журнал вручную: %APPDATA%\Konverter\konverter.log
3. Если колесо не появляется при перетаскивании — проверь, что антивирус
   не блокирует программу, и что в журнале нет строки «Не удалось включить
   слежение за перетаскиванием».

УДАЛЕНИЕ
Удали папку с программой и ярлыки. LibreOffice, Ghostscript и среда C++
удаляются обычным способом через «Параметры → Приложения».
